# RoboPaintBench 发布方案

首版采用 **GitHub repo + GitHub Pages 展示页 + Colab 运行入口 + B站/YouTube 视频**。无需购买服务器。仓库负责可复现与版本，网页负责第一印象、画作比较和方法说明，视频负责传播，Colab负责用户自行启动计算。

## 首版定位

名称沿用 **RoboPaintBench**。英文主标语：**From pixels to physical strokes.** 中文可以叫“从视觉到落笔：大模型机器人绘画基准”。

介绍应当聚焦一个可验证的问题：大模型能否根据相机反馈，规划机械臂的三维运动，把目标变成画布上的笔迹。它是一项细粒度的模拟具身控制研究，不宜从一个固定目标直接推广为整个具身领域的能力总排名。

首屏用真实画作，配真实机器人录像。不给模型生成“更漂亮的示意画”，也不把美化图当结果。两个固定目标各有33张画布，共66张结果足够形成视觉对照，封面无需依赖ImageGen。

## 第一阶段：金门大桥首发

页面已按11模型、33最终画布组织，支持attempt切换、三轮进程查看、并排比较与实际推理设置。默认采用作者于 **2026-10-19** 提供的个人主观排名：**Astra → Sol → Argon → Opus → DeepSeek → Wonder（Meta）→ Qwen → MiMo → Kimi → Grok → Doubao**。页面明确标为“作者个人推荐排序”，保留署名和日期；它不是数值画质指标或多人共识排名。字母排序可作为另一种浏览方式。

Grok以最新完成资料为准：96 / 96 / 47步；其中一个harness预算失败被记录为无移动拒绝步。Opus混合推理设置、MiMo输出预算提高与Astra SDK传输差异保留在实际设置说明。没有把不同推理预算宣称为等算力比较。

推荐顺序已由作者确认。正式公开前尚需确认：所选媒体的公开与许可；仓库可见性；公开运行资源的无授权下载验收。付费API推理与云端GPU未在此次静态开发中重新运行。

## 第二阶段：鹈鹕

鹈鹕资料已按同一证据格式整合：11模型、33轮、603动作，完整record固定HF提交，11段三轮成片按模拟时间4倍速播放。准确输入、各模型实际设置、trajectory窗口限制与回放范围见[鹈鹕说明](pelican-results.md)。纯文字是**没有参考目标图**，仍然有两路工作区图像。两个任务在首页切换，结果、视频和Colab入口分别选择；鹈鹕没有画质排名，不沿用金门大桥推荐顺序，也不作未经定义的合并总分。公开网页部署与媒体发布仍需按实际发布范围单独处理。

## 第三阶段：自定义绘画

提供文字、单图、多图教程与Colab入口。调整力夹笔、有限颜料/笔刷干涸、画板随机化等需要标明条件。开放绘画是体验入口，不混进固定目标的正式比较。

Colab首版应标清预览属性：Python版本、可用GPU与图形栈、运行资源访问权限、模型API密钥都可能影响能否启动。把“打开notebook”和“已在全新Colab跑通”作为不同状态。

## 传播内容

建议解说视频按以下顺序组织：原始现实机器人演示引入 → 这里模型实际看到什么和可以做什么 → 同一参考下的11模型画作 → 两个模型的过程片段与三轮变化 → 失败也保留的结果墙 → 复现和自由绘画入口。

封面与标题突出“机器人落笔”和真实对比。避免使用未经评分的“全行业第一”、统计显著性、通用机器人能力结论。可以使用你的署名推荐与实际画作证据。完整视频上传后填入准确attempt对应链接；解说视频后来补入，不放占位的虚假播放按钮。

匿名人工两两比较工具作为后续可选研究补充，首版无需等待三位评分者。若要正式报告测量排名，应执行并记录相应评分协议，而不是把推荐排序改名为客观得分。
